
# AmritKaurOS v3 🌸

This is a richer prototype build for AmritKaurOS:
- Punjabi AI-sim Console (local, rule-based)
- Naam Halo visual, Naam Tree image
- Healing audio (placeholder) and memory import/export
- All client-side so you can host on GitHub Pages

Install:
1. Upload these files to your repository root (index.html, style.css, app.js, memory.json, assets/*).
2. Enable GitHub Pages (main branch / root).
3. Visit the pages URL and Add to Home Screen on iOS if desired.

Notes:
- This prototype uses localStorage for memory (no server). Keep backups by Export feature.
- Replace assets/healing.mp3 with a real audio file when ready.
- For full AI (server-backed) let me know and we'll plan next steps.
